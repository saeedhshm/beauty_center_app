# لوحة إدارة لمسة

المراحل المنفذة حاليًا هي `D0` إلى `D6` من خارطة `DATABASE_README.md`: أساس React/TypeScript/Vite/MUI، جلسة المدير، حماية المسارات، وصفحة البداية، ثم شاشات الخدمات والخبيرات (مع المراجعة والاعتماد والتعليق والوثيقة) والحجوزات (مع التفاصيل والسجل والإلغاء)، ثم الحسابات (مع التعطيل والتفعيل) والتقييمات وسجل التدقيق، ثم المدفوعات (مع التفاصيل والاسترجاع) والمستحقات (مع الإنشاء من المؤهلة والتحويل اليدوي)، ثم الملخص التشغيلي (تجميعات الخادم عبر كامل البيانات في فترة بتوقيت Africa/Cairo) وصفحة التشغيل (التسليمات الفاشلة مع إعادة المحاولة عبر الـWorker، والمدفوعات المتأخرة للمراجعة، وحالة آخر دورة Worker)، ثم الإعدادات (حقول ظاهرة لتعديل المهل والعمولة خلف تأكيد وتدقيق، وإنشاء المدن وتفعيلها/تعطيلها وحذف غير المستخدمة منها، وتغيير عملة السوق بين EGP وSAR خلف تحذير صريح). الواجهة كاملة بالعربية والإنجليزية مع RTL/LTR واختيار محلي للمتصفح؛ تبقى منطقة وقت الأعمال `Africa/Cairo` وعملة كل سجل التاريخية مستقلتين عن لغة العرض. لا توجد عناصر معطلة في التنقل ولا بيانات تجريبية توحي باتصال غير حقيقي.

## التشغيل المحلي

شغّل Backend أولًا على `http://127.0.0.1:3000`، ثم من هذا المجلد:

```sh
npm install
npm run dev
```

يفتح Vite عادةً `http://127.0.0.1:5173`، ويمرر `/api` و`/health` إلى Backend. إذا كان الخادم على منفذ آخر، أنشئ `.env` محليًا دون إضافته إلى Git:

```dotenv
DASHBOARD_API_TARGET=http://127.0.0.1:3100
```

بيانات مدير العرض الخيالية موثقة في `../backend/docs/catalog.md`. لا تستخدمها في بيئة حقيقية.

## عقد الجلسة

- تستخدم اللوحة `/api/v1/admin/*` فقط وجلسة Bearer ذات audience إداري.
- access token في الذاكرة، وrefresh token في `sessionStorage` لتجاوز إعادة تحميل التبويب دون استمرار بعد إغلاقه.
- طلبات `401` المتزامنة تشترك في refresh واحد. لا يعاد طلب refresh القديم، لأن Backend يبطل الجلسة عند اكتشاف إعادة استخدامه.
- عند فشل refresh تُمسح الجلسة ويعود المستخدم إلى صفحة الدخول.
- تسجيل الخروج يمسح الجلسة محليًا حتى إن كانت الشبكة غير متاحة.

الـDashboard يعتمد مسارات نسبية. في الإنتاج يجب أن يمرر reverse proxy مسار `/api` إلى Backend، أو يضاف CORS ضيق للـorigin المعتمد بدل فتح CORS عام.

## بناء الإنتاج والتشغيل

```sh
npm run build
```

يُنتج مجلد `dist/` static يُقدَّم خلف reverse proxy على نفس المصدر مع تمرير
`/api` و`/health` إلى Backend — لا يتصل Dashboard بقاعدة بيانات أو أسرار.
لا CORS عام مطلوب. أخطاء الواجهة تُعرض للمشغّل مع `requestId` من الخادم دون
إرسال بيانات شخصية أو مالية لأي خدمة خارجية (لا مفتاح تتبع بعد).
