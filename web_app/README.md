# مكونات الويب في لمسة

- `backend/`: أساس API واتصال قاعدة البيانات، وتعريفات Drizzle وmigrations للجداول الـ17 مع اختبارات PostgreSQL معزولة.
- `dashboard/`: أساس لوحة الإدارة العربية RTL منفذ بجلسته المحمية وصفحة البداية؛ وحدات التشغيل التالية لم تُربط بعد.
- تطبيقات الهاتف مكانها `../flutter_app/`.

ابدأ من [دليل تشغيل Backend](backend/README.md). وثائق المنتج والقرارات في جذر المشروع، ووثيقة الداتابيس هي `../DATABASE_README.md`.
تشغيل ونطاق لوحة الإدارة في [دليل Dashboard](dashboard/README.md).
